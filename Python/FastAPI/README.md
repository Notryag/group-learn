# FastAPI 学习

学习模式：快速学习。先运行一个最小接口，再通过练习确认会用。

FastAPI 是用 Python 编写 Web API 的框架：客户端发送 HTTP 请求，服务端执行 Python 函数并返回数据。

## 学习路线

| 后续章节 | 路径参数、查询参数和请求体 | 未学习 |
